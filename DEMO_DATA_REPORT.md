```

Area    = Mumbai locality           →  "Kandivali", "Kurla", "Chembur"

                                          "Apollo Multispecialty Clinic Kurla",
```

## Integrity guarantees (verified after seeding)

- ✅ **Hierarchy** Tenant → Area → Clinic → Program → Doctor → Patient respected.
- ✅ **Doctors only in their own clinic** — each doctor is assigned to exactly one clinic;
  every doctor↔patient assignment is at that doctor's clinic.
- ✅ **Patients** belong to one clinic (in their area) + one doctor that works at that clinic.
- ✅ **Full role spread per tenant**: AREA_ADMIN, CLINIC_ADMIN, DOCTOR, OPERATOR, STAFF, each
  with appropriate clinic assignments (admins → all/area clinics, doctors → own clinic).
- ✅ **Unique identifiers**: 1320 unique emails, 1320 unique phones, 900 unique NHS numbers.
- ✅ **No hardcoded IDs** (all `@default(uuid())`); **no orphan records**.

## Idempotency

Running the seed twice produced identical DB counts (no duplicates). Enforced by upserts on
natural keys (tenant `domain`, area `(tenantId,name)`, clinic `(areaId,name)`, program
`(tenantId,activationCode)`, user `email`, patient `(tenantId,nhsNumber)`, clinic assignment
`(userId,clinicId)`) and deterministic generation (fixed PRNG seed).

## How to run

```bash
cd artifacts/api-server
pnpm run demo:build   # regenerate prisma/demo-data.json (deterministic)
pnpm run demo:seed    # upsert into the DB (idempotent — safe to repeat)
```
